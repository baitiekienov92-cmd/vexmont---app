# Vexmont — приложение прораба и ОКК

Регистрация по телефону, роли (администратор, ОКК, прораб, заказчик), ЖК и квартиры, 18 этапов с приёмкой ОКК, фотоотчёты, история, уведомления. Ставится на телефон как приложение.

## Запуск на Render
1. GitHub → новый **приватный** репозиторий `vexmont-prorab` → загрузить все файлы этой папки (вместе с `templates` и `static`).
2. Render → **New → Blueprint** → выбрать репозиторий → **Apply**. Создадутся сервис и база PostgreSQL.
3. Через 3–5 минут откройте ссылку `https://vexmont-prorab.onrender.com`.

## Первый вход
- **Первый зарегистрированный становится администратором** — зарегистрируйтесь сами сразу после запуска.
- Создайте ЖК: Профиль → Объекты → «Новый ЖК», номера квартир: `1-42` или `187, 193, 199`.
- Сотрудники регистрируются сами по ссылке и выбирают роль. Вы подтверждаете их в Профиль → Сотрудники и отмечаете, к каким ЖК открыт доступ.

## Должности и доступ
| Должность | Что может |
|---|---|
| Генеральный директор | Всё: сотрудники, объекты, финансы, доступ к каждому договору |
| Директор по развитию | Объекты, юр. отдел (договоры, открытые ген. директором) |
| Руководитель проекта, Начальник участка, Прораб | Сдают работы («Вызвать ОКК»), фото, замеры, заявки |
| Инженер ОКК | Дефектный акт (этап 1), приёмка и возврат работ |
| Снабжение | Заявки на закуп, назначение замеров |
| Юрист | Создаёт договоры и загружает файлы |
| Бухгалтер | Юр. отдел по доступу; график выплат, если открыт доступ |
| Заказчик | Только просмотр своей квартиры: этапы, проценты, фото |

## Финансы (только ген. директор)
Расходы по блокам и квартирам, план/факт (план из Excel, факт — оплаченные заявки и выплаты по графику), лимиты на черновые и чистовые материалы, график работ и выплат с зелёными/красными кнопками, заявки на выплату и закуп.

## Установка на телефон
- Android (Chrome): открыть ссылку → ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
